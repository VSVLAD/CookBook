---
layout: recipe
title: Жаренные кабачки с майонезом и чесноком
description: Холодная закуска или лёгкий гарнир для летних блюд. При желании можно
  сверху ещё ломтик помидорки добавить. С чесноком вкуснее, добавлять обязательно
  😊
prep_time: 40 минут
servings: 4-6 порций
preview: /assets/images/zharennye-kabachki-s-mayonezom-i-chesnokom-preview.jpg
ingredients:
- name: 2 шт. кабачки
  isHead: false
- name: мука для панировки
  isHead: false
- name: 100 гр майонез
  isHead: false
- name: 3-4 зубчика  чеснок
  isHead: false
- name: растительное масло для жарки
  isHead: false
steps:
- name: Шаг 1
  description: Помыть и порезать кольцами кабачок
  images:
  - /assets/images/zharennye-kabachki-s-mayonezom-i-chesnokom-step-1-1.jpg
- name: Шаг 2
  description: Обвалять каждый кусочек в муке и выложить на разогретую сковороду с
    растительным маслом
  images:
  - /assets/images/zharennye-kabachki-s-mayonezom-i-chesnokom-step-2-1.jpg
- name: Шаг 3
  description: Обжаривать с каждой из сторон около 1.5 минуты, пока не возьмутся корочкой.
    Масло доливаем по мере того, как впитывается. Мука подгорает немного, но это не
    критично.
  images:
  - /assets/images/zharennye-kabachki-s-mayonezom-i-chesnokom-step-3-1.jpg
- name: Шаг 4
  description: Оюжаренные кабачки выкладываем на несколько слоёв бумаги (газета/салфетки)
    и даём кабачкам остыть и уйти лишнему маслу
  images:
  - /assets/images/zharennye-kabachki-s-mayonezom-i-chesnokom-step-4-1.jpg
- name: Шаг 5
  description: Майонез смешиваем с чесноком, предварительно мелко порезанным или пропущенным
    через чеснокодавку. Наносим на каждый кружок слой майонеза. Остывшие кабачки убираем
    в холодильник на полноценное охлаждение. Не солил и не перчил, т.к. по мне майонез
    уже имеет достаточно соли. Так что солить дополнительно при желании. Блюдо готово
  images:
  - /assets/images/zharennye-kabachki-s-mayonezom-i-chesnokom-step-5-1.jpg
