description: Просто вкусные маринованные грибы и лучок. Идеально подойдёт к жареной
  картошке в качестве холодной закуски.
prep_time: 30 минут
servings: 4 порции
preview: /assets/images/a64a1c6f4627294e.jpg
ingredients:
- name: 300 гр грибы "вёшенки"
  isHead: false
- name: 2 шт лук репчатый
  isHead: false
- name: по вкусу уксус
  isHead: false
- name: масло растительное
  isHead: false
- name: перец горошком
  isHead: false
- name: лавровый лист
  isHead: false
steps:
- name: Шаг 1
  description: Хорошо промоем грибы чистой водой, разделим на отдельные полоски.
  images:
  - /assets/images/24d94065d7d6b532.jpg
- name: Шаг 2
  description: В кипящую подсоленную воду кладём грибы, перец и лавровый лист. Варим
    грибы около 25 минут.
  images:
  - /assets/images/fadab6b01776ebd1.jpg
- name: Шаг 3
  description: Тем временем чистим лук, режем кольцами и сбрызгиваем хорошо уксусом.
    Количество уксуса по вкусу.
  images:
  - /assets/images/4f9760666817eda1.jpg
- name: Шаг 4
  description: Сливаем воду из под грибов и высыпаем их в чашу с луком. Перемешиваем,
    даём остыть и домариноваться часик другой, но можно и кушать сразу. Лучок будет
    уже готовый
  images:
  - /assets/images/cd74e268706d4b26.jpg
