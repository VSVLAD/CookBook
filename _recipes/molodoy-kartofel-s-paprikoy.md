title: Молодой картофель с паприкой
description: 'Очередная ленивая еда: жаренный картофель и мяско на противени. Чистить

prep_time: 1 час
servings: ''
preview: /assets/images/molodoy-kartofel-s-paprikoy-preview.jpg
ingredients:
- name: 1 кг куриные голени
  isHead: false
- name: 500 гр  молодой картофель
  isHead: false
- name: 1 шт помидор (не водянистый)
  isHead: false
- name: 1 шт красный лук
  isHead: false
- name: 1 шт. морковь
  isHead: false
- name: 50-100 гр майонез
  isHead: false
- name: По вкусу растительное масло, паприка, соль и перец
  isHead: false
steps:
- name: Шаг 1
  description: Молодую картошку можно только вымыть, чистить не нужно. Перекладываем
    ингредиенты в таз или большую миску в которой будем всё перемешивать.
  images:
  - /assets/images/molodoy-kartofel-s-paprikoy-step-1-1.jpg
- name: Шаг 2
  description: Добавляем лук, морковь нарезанную на крупные кружочки, майонезик, помидоры,
    растительное масло, паприку, соль и молотый черный перец. Помидоры я немного "отжал",
    т.к. не хотелось, чтобы выделилось много жидкости и овощи сварились в ней.
  images:
  - /assets/images/molodoy-kartofel-s-paprikoy-step-2-1.jpg
  - /assets/images/molodoy-kartofel-s-paprikoy-step-2-2.jpg
- name: Шаг 3
  description: Перекладываем наш продуктовый набор на противень.
  images:
  - /assets/images/molodoy-kartofel-s-paprikoy-step-3-1.jpg
- name: Шаг 4
  description: Отправляем в печь на 50 минут при температуре 180°. Периодически проверяем
    вилкой картофель, если будет мягкий, готовку заканчиваем.
  images:
  - /assets/images/molodoy-kartofel-s-paprikoy-step-4-1.jpg
- name: Шаг 5
  description: Можно кушать.
  images:
  - /assets/images/molodoy-kartofel-s-paprikoy-step-5-1.jpg
