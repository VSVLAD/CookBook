  isHead: false

  isHead: false
- name: 1 шт помидор (не водянистый)
  isHead: false
- name: 1 шт красный лук
  isHead: false
- name: 1 шт. морковь
  isHead: false
- name: 50-100 гр майонез
  isHead: false
- name: По вкусу растительное масло, паприка, соль и перец
  isHead: false
steps:
- name: Шаг 1
  description: Молодую картошку можно только вымыть, чистить не нужно. Перекладываем
    ингредиенты в таз или большую миску в которой будем всё перемешивать.
  images:
  - /assets/images/c73819d11c0bbfd6.jpg
- name: Шаг 2
  description: Добавляем лук, морковь нарезанную на крупные кружочки, майонезик, помидоры,
    растительное масло, паприку, соль и молотый черный перец. Помидоры я немного "отжал",
    т.к. не хотелось, чтобы выделилось много жидкости и овощи сварились в ней.
  images:
  - /assets/images/a68f6341f5459c4e.jpg
  - /assets/images/2d4fce67fc947ed1.jpg
- name: Шаг 3
  description: Перекладываем наш продуктовый набор на противень.
  images:
  - /assets/images/7a3348550ff920ba.jpg
- name: Шаг 4
  description: Отправляем в печь на 50 минут при температуре 180°. Периодически проверяем
    вилкой картофель, если будет мягкий, готовку заканчиваем.
  images:
  - /assets/images/ca8791fb8ea3931e.jpg

  description: Можно кушать.
