# Коротко о репозитории
Посмотреть книгу можно ссылке: https://vsvlad.github.io/CookBook/

# Структура проекта
* index.md — главная страница, которая автоматически выведет список всех рецептов из папки _recipes/
* assets/images/ - список всех картинок
* _layouts/recipe.html — шаблон для отображения отдельного рецепта (название, превью, метаданные, ингредиенты и шаги с картинками)
* _config.yml — конфигурационный файл Jekyll
