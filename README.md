# 🍳 Моя домашняя кулинарная книга

Добро пожаловать в мой сборник домашних рецептов! Этот проект создан для личного пользования в свободное время — здесь собраны проверенные временем любимые блюда, закуски, выпечка и десерты с пошаговыми инструкциями и фотографиями.

Сайт работает на базе **GitHub Pages** и **Jekyll**, оформлен с использованием **Bootstrap 5**, а также оснащен быстрым инлайн-поиском по каталогу рецептов прямо в браузере.

## 🛠️ Техническая информация и добавление новых рецептов

Если вы хотите добавить новый рецепт в эту коллекцию или склонировать репозиторий для себя, вам потребуется создать Markdown-файл в папке `_recipes/` и разместить соответствующие изображения в папке `assets/images/`.

### 1. Формат именования изображений
Все картинки хранятся в плоском каталоге `assets/images/`:
- **Превью рецепта:** `{slug-рецепта}-preview.jpg`
- **Фотографии шагов:** `{slug-рецепта}-step-{номер_шага}-{номер_фото}.jpg` *(например: `borsch-step-1-1.jpg`, `borsch-step-2-1.jpg`)*

### 2. Структура и ключи Markdown-файла рецепта
Каждый рецепт представляет собой `.md` файл в папке `_recipes/` со следующим Frontmatter (метаданными):

```yaml
---
layout: recipe
title: "Название рецепта"
description: "Короткое описание блюда..."
prep_time: "40 минут"
servings: "4 порции"
preview: "/assets/images/nazvanie-recepta-preview.jpg"
ingredients:
  - name: "Название категории ингредиентов (если нужно)"
    isHead: true
  - name: "Ингредиент 1 — 500 г"
    isHead: false
  - name: "Ингредиент 2 — по вкусу"
    isHead: false
steps:
  - description: "Описание первого шага приготовления..."
    images:
      - "/assets/images/nazvanie-recepta-step-1-1.jpg"
  - description: "Описание второго шага..."
    images: []
---
```

### Описание полей:
- `layout`: всегда должен быть `recipe`.
- `title`: название рецепта.
- `description`: краткая вводная или пара слов о блюде.
- `prep_time`: время приготовления (строка).
- `servings`: количество порций или штук (строка).
- `preview`: путь к главной картинке рецепта.
- `ingredients`: список ингредиентов. Если элемент является заголовком группы (например, «Для теста» или «Соус»), укажите `isHead: true`, иначе `isHead: false`.
- `steps`: список шагов приготовления. Каждый шаг содержит `description` (текст) и массив `images` со списком путей к фотографиям шага (или пустой список `[]`, если фото нет).
